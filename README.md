## Para clonar los archivos al Visual Studio Code

- Abrir el XAMPP Control Panel
- Activar el Apache y el MYSQL
- Luego abrir el Visual Studio Code y abrir la terminal y hacer:

```git
git clone -b FrontEnd https://github.com/Lakeret/Clinica-Privada-.git
```
